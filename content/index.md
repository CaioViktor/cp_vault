## 📚 Principais Categorias de Crimes

Para facilitar o estudo, os crimes estão agrupados conforme a tutela jurídica do Código Penal:

| Categoria / Titulação | Exemplos de Crimes Incluídos |
| :--- | :--- |
| **Crimes contra a Pessoa** | Homicídio, Aborto, Lesão Corporal, Abandono de Incapaz |
| **Crimes contra o Patrimônio** | Furto, Roubo, Estelionato, Dano, Receptação |
| **Crimes contra a Dignidade Sexual** | Estupro, Assédio Sexual, Divulgação de Cena de Estupro |
| **Crimes contra a Fé Pública** | Moeda Falsa, Falsificação de Documento Público, Falsidade Ideológica |
| **Crimes contra a Administração Pública** | Peculato, Concussão, Corrupção Passiva, Prevaricação |
| **Crimes contra a Incolumidade / Paz Pública** | Incêndio, Associação Criminosa, Milícia Privada |
